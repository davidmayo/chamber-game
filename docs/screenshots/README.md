# Afterglow / Signal Archive

Actual Unity Play Mode views of the new room beneath the DOC, captured at 1920 by 1080. The sculpture, room lighting, world-space displays, and floor reflection are rendered live. The reproducible photography pass stages the receiver and playback state and omits the overlay HUD; these are not concept renders or edited images.

## Orbital

Intersecting cyan and amber paths wrap a woven globe. Moving points follow the paths above the polished inset.

![Orbital recording](afterglow-orbital.png)

## Pulsar

The globe changes into a warm hourglass surrounded by stacked orbital rings.

![Pulsar recording](afterglow-pulsar.png)

## Aurora

A folded curtain of colored light moves through the suspended field.

![Aurora recording](afterglow-aurora.png)

To visit: take Stair 01 at the far end of the chamber hallway, descend to the cable gallery, and follow the Afterglow signs past the Null Reference Lab. Energize the three receiver banks with F, then use the playback bench beside the entrance.

To recapture: enter a fresh Play session in Main, then run `powershell -NoProfile -ExecutionPolicy Bypass -File tools\unity-bridge.ps1 capture_archive -NoWait`. The command exits Play Mode after writing these photographs.
