## Space Science Center Skunk Works / Level 02

Sixteen actual Unity Play Mode views at 1920 by 1080. The three prototype controllers animate the scene before each photograph; HDR bloom and tone mapping run through the player camera. The photography pass stages session progress and omits the overlay HUD. These are game renders, without image editing.

At the DOC truck stop, board with **F**, choose **2**, and press **W once**. Follow the colored guides through Helios Forge, Vector Garden, and the Horizon Engine. [Gameplay procedure](../skunk-works.md).
